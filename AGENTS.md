# Project workflow

- Implement only the experiment step the user currently requests.
- After completing and checking each requested step, commit and push it to
  `master` in `https://github.com/Maitham16/Artificial_Evolution.git`.
- Keep `.venv`, caches, bytecode, and operating-system files out of Git.
- If this workspace prevents writes to `.git`, perform Git operations in a
  permitted temporary checkout and copy only the intended project files.
