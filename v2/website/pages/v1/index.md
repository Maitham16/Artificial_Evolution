# V1 · Original 2D simulator

The original Python/Pygame application is the project's scientific workbench and preserved research record. It remains independently accessible alongside V2.

[![Actual original 2D research workbench with living creatures, controls, neural preview and plots](../assets/gallery/v1-original.jpg)](../gallery/index.md#one-engine-two-views)

## Start the workbench

From a prepared repository root:

```bash
./.venv/bin/python simulator.py
```

For a new environment, follow the [installation tutorial](../getting-started/index.md). Public source and research archives are available under [downloads](../downloads.md).

## Explore the research tools

V1 contains seven live worlds, controller and reproduction settings, ancestry visualization, run exports and 15 study recipes. The existing scripts own the published experiment protocols. The 3D interface does not replace that background study catalog.
