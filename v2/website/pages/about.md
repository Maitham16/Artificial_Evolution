# About the project

Artificial Evolution explores how neural controllers and inherited traits change under survival and reproduction. V1 provides the original 2D research simulator; V2 adds a Godot 3D desktop view over the same Python engine, plus an explicitly separate optional physical habitat.

The supported scientific claim is adaptive behavior under defined conditions. Read [research methods and limitations](research/index.md) alongside the gallery.

Project code uses the [MIT license](assets/LICENSE.txt). Animal and landscape sources have recorded CC0 licenses. Dependency and engine notices accompany desktop packaging; Blender is an external authoring tool.

## Documentation and media

The site uses MkDocs Material with a custom visual layer. Existing Markdown is the source of the V1/V2 guides; the website adapts links, metadata and presentation only in generated output. Original applications, numerical code, tests, datasets and Markdown files remain intact.

The [gallery](gallery/index.md) uses real application captures. Its manifest records source hashes, configurations, timings and exported metrics. Website videos require explicit playback; their looping GIF equivalents remain available from the original gallery files.
