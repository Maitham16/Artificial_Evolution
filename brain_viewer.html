Inside evolved controllers

Recorded decisions from frozen brains. Select a creature, play its trajectory, or scrub to inspect the inputs, hidden activations, and output commands at that decision.

Individual trajectory

Teal: trail and heading · orange rings: meals so far · gold: current sensed target · grey: initial food only. Food is replenished during the run.

Neural decision at the same instant

Node colour shows signed activity (blue positive, red negative); edges show signed weights. Activations include biases. Each hidden unit uses tanh. Speed stays at 60 pixels/s, so throttle has no movement effect.

Local turn sensitivity

Exact ∂turn/∂input at this state, per encoded input unit. Positive means increasing that input increases rightward turning. This is a local response, not a fitness effect or a standardized importance ranking.

Zero one hidden activation

Original turn minus the turn with one hidden activation set to zero for this decision. Units can compensate for each other; neuron indices have meaning only within this network.

Examples use the first declared source seed and IDs 1, 34, 67, chosen before outcomes. The study summarizes all 100 brains in each source seed group. No training occurs during recording. State samples are 0.2 seconds apart; playback does not interpolate physics or unrecorded decisions. These feed-forward controllers have no recurrent memory; traces do not establish planning.
